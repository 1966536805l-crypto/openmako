# Claude Code 可借鉴部分

这份文档只记录架构层面的安全结论，不复制来源不明的实现代码。

## 可以借鉴

- Agent loop: 模型不是一次性回答，而是反复调用工具、接收结果、继续推理。
- Tool boundary: 工具层必须独立，执行命令、读写文件、网络访问都要有统一入口。
- Project memory: 启动时先读项目规则和最近状态，避免每轮重新解释背景。
- Permission guard: 越是想要高自动化，越要防误删、误跑、误泄露。
- Report trail: 每次实验必须留下 Markdown/JSON 证据链。
- Model adapter: 模型供应商要隔离在 adapter 层，不让业务逻辑绑定某个网关协议。

## 不应该照搬

- 不运行来源不明的 `cli.js` 或 npm tgz。
- 不复制泄露源码到自己的工具。
- 不做封号规避、限制绕过、协议伪装。
- 不把 API key 写进源码、报告或交接文件。

## 对量化项目的改造方向

- 每个结论必须绑定数据版本、样本数、滑点假设、去重状态。
- 默认读取去重后基准，不读取 1253 笔污染旧样本。
- 自动审计未来函数：尤其是 entry/exit 时间线、09:25 信号和 09:30 买入混淆。
- 自动审计成交模型：成交额单位、滑点、涨跌停不可成交、容量占比。
- 自动触发双模型复核，但最终以可复现实验结果为准。
